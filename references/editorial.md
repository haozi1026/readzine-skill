# 编辑与固定风格

## 长难句

核心判断：读者知道主要词义之后，是否仍容易因结构读错或漏掉重要关系？优先保留明显结构障碍，中等难度结合文章作用与教学收益取舍。重要性不能让简单句入选，不设条数或比例。显著难句保留；中等且高度重复的结构可选典型例，指代、否定范围不同的句子不能仅凭同标签删除。

候选结构包括：多层从句嵌套；较长插入导致主谓/动宾分离；多层修饰、关系词与代词的归属；倒装、形式结构、强调或省略需要还原；复杂并列与否定、比较、让步、条件的范围。一个普通从句、简单列举、普通被动、抽象观点或陌生术语单独出现都不是充分理由。

每句在 `reason` 记录具体难点与误读风险。首层按原句（主干蓝、从句赭、修饰绿）、完整翻译、英文主干与中文说明、读懂关键排列。不要删除必要补足、否定、情态或时态后仍称为完整主干。嵌套颜色只表示当前层作用；定语从句可标绿色修饰，在子块说明语法层级。详细层块数按实际需要，按原文顺序，不同层可以嵌套，同层不重叠。只有实际存在特殊语序或省略时才提供 `restoration`；原文、主干、语序还原、理解概括各自标明。

例如：Although taking a break may appear unproductive in a culture that values constant activity, it can create the mental space in which new ideas begin to form.

主干是 It can create the mental space.，it 指 taking a break。先识别 Although 让步背景，再找 it can create，最后将 in which 接回 mental space。that values constant activity 嵌在让步从句内修饰 culture，不是并列主线。完整译文保留“尽管”“可能”“能”和“新想法开始形成”。

## 七套固定模板

选风格需判断主旨、语气、论述方式与图片条件，不是关键词匹配。每套共用同一阅读逻辑、660px 单栏英文正文与中文解析，题材不限制真实难句数量。刷新不重新随机。

| ID | 适配倾向 | 固定视觉与布局 |
| --- | --- | --- |
| warm | 教育、心理、生活、温和说明；不确定时回退 | #F7F4EC 暖纸、#242822 墨色、#9E493A 砖红；封面左文右图，Georgia 大标题，首段后配图、轻段号、首字下沉 |
| cinema | 自然、环境、地理、户外和场景叙事 | #F3F2E9、#27332B、#506648；封面大图加深色渐变和浅色叠字，留白与对比度经过检查；正文照片开篇 |
| modern | 商业、创新、数字生活、产品与技术分析 | #FAFAF7、#172C3A、#275871；居中无衬线大标题，下文再下横幅；正文左侧主题栏、右单栏，标题后图注并排，无下沉字 |
| newspaper | 社会、经济、公共议题、历史评论 | #F1ECDF、#302C25、#65513A；双线刊名、跨栏大标题、左图右导语；正文标题居中，中段细线图片，正文不分栏 |
| gallery | 人物、文化、艺术、文学、审美表达 | #F7F3EF、#3E333D、#82586F；左大图、右下错位文字，衬线斜体、留白；正文稍宽图片，手机先图后文 |
| science | 科学机制、能源、原理、实验解释 | #F5F8F9、#17384B、#14727C；跨栏无衬线标题、观察图片与简介网格，细网格纹理；标题后图文模块，不编造图解数据 |
| bright | 教育、心理、生活方式、抽象社会观念 | #FFF9EE、#253B61、#BA5038；成熟概念插画，左无衬线标题、右插画；手机标题入口在上，首段后插画 |

颜色映射固定为主干 #255879/#E4EDF0、从句 #835515/#F5EBD6、修饰 #3E6754/#E7EEE6，不随品牌色改变。只对当前激活句和解析显示颜色，正文其他句保持轻标记。

暖纸封面标题桌面约60–76px、手机52–59px；正文标题48/38px、英文正文20px/1.87（手机18px/1.85）；段距24px。宽屏350px抽屉让正文留出空间，窄屏接近全屏、明显关闭和键盘退出；词卡约270px、不可越界。样式已经实现在 assets，生成文章时更新数据即可。
